Prioritization Engine: 0–100 Scoring Formula

Transparent calculation replacing arbitrary date-sorting with multi-factor constraint evaluation.

40 pts
Deadline Proximity
Exponential decay based on hours remaining until due date. Under 4 hours awards maximum weight.
25 pts
Commitment Consequence
Hard external deliverables (client milestones, graded exams) vs. flexible internal research tasks.
20 pts
Calendar Slot Fit
Task duration matches the next available free block before an upcoming class or meeting.
15 pts
Importance Base Weight
Base priority tag (High, Medium, Low) assigned by source feed or user override.
Do Now: Score ≥ 80 Do Next: Score 50 – 79 Do Later: Score < 50

Component Mapping & Specifications

Click each component to inspect its implementation file, responsibilities, and PRD requirement link.

src/components/dashboard/DailyBriefing.tsx Implements: prd.md > 1. Daily Briefing & Overload Detection
Renders the top summary banner. Calculates total required workload hours vs. open calendar free hours. Activates the Overload Alert banner with exact deficit calculations when time is oversubscribed.
Inputs / State
tasks: Task[], calendarEvents: CalendarEvent[] from AppContext.
Key Outputs
Active tasks count, Workload vs. Free Hours chips, Overload capacity deficit badge.
src/components/dashboard/PriorityColumns.tsx & TaskCard.tsx Implements: prd.md > 2. Prioritized Task Columns
Renders Do Now, Do Next, and Do Later columns. Each card supports marking complete, expanding mathematical score breakdown in TaskReasonModal.tsx, and manual priority override dropdown.
Inputs / State
tasks: Task[] filtered by bucket (now, next, later).
Interactions
toggleTaskComplete(), updateTaskPriority(), open reason modal.
src/components/dashboard/DailyTimeline.tsx Implements: prd.md > 3. Daily Timeline Visualizer
Plots a single-day 8:00 AM – 10:00 PM horizontal timeline. Visually distinguishes fixed commitments (classes, meetings) from scheduled focus blocks allocated to Do Now tasks.
Inputs / State
scheduler.ts computed intervals mapping tasks to calendar open gaps.
Visual States
Fixed event blocks (neutral gray), Focus blocks (violet), Open free gaps (dashed).
src/components/assistant/AIAssistant.tsx & ApprovePlanCard.tsx Implements: prd.md > 4. AI Dialogue & Approve Plan Changes
Handles conversational challenges. When user requests rebalancing (e.g. studying for exam first), it generates an ApprovePlanCard detailing structured diffs and deadline risks before modifying the board.
Safety Contract
No schedule shifts occur until user clicks "Approve Changes".
Actions
applyPlanProposal() dispatches new task buckets; "Reject" retains current plan.
src/engine/prioritizer.ts & scheduler.ts Implements: prd.md > The Core Journey & Features 1, 2
Pure deterministic TypeScript logic. Computes 0–100 priority scores, evaluates deadline proximity, detects capacity gaps, and slots focus intervals into open calendar windows.
Performance
Executes in < 5ms in-browser with zero network overhead.
Reliability
100% deterministic outputs for rehearsable 60-second video demo recording.
src/components/integrations/IntegrationsView.tsx & Modals Implements: prd.md > 5. Mock Integrations Manager & Controls
Dedicated view showcasing active mock feeds (Gmail, Canvas, Calendar, Tasks). Contains "Reset Demo Data" confirmation modal and "Add Mock Task" creation form.
Demo Utilities
resetToDemoSeed() wipes custom changes and restores baseline state.
Testing Tools
addMockTask() injects a custom task directly into prioritization.
