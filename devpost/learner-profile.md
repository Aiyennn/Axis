# Learner Profile

## Initial Idea
Axis — an AI-powered productivity command center that consolidates scattered inputs (emails, calendars, to-do lists, school assignments, freelance projects, work tasks) into one platform. For this prototype: a platform-independent experience using mock integrations (email, calendar, task manager, school/project portals) with realistic sample data. Key features: modern dashboard with a daily briefing, unified tasks prioritized into "Do Now", "Do Next", and "Do Later", upcoming deadlines, daily planner, mock integrations hub, and an AI assistant to explain recommendations and answer workload questions. Core technical challenge: an intelligent AI prioritization engine factoring in deadlines, urgency, importance, duration, dependencies, and available time with transparent explanations and user overrides.
